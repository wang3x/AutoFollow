# 强效跟随 AutoFollow

基于 **vnavmesh** 的 FF14 自动跟随插件。  
设定目标 → 自动追上 → 靠近后停跟并恢复输出 → 走远后继续追。

## 自动小队跟随与传送恢复

服务器信息栏新增 `跟随 OFF/ON`，默认 OFF。ON 后优先跟随唯一存活在线的 T，多 T 跟队长；无法选中有效目标时选择其他有效队友，绝不跟随自己。目标丢失后只做一次有限传送尝试，无法继续时停止移动。

完整规则、入口配置、直线移动限制与游戏内验收清单见 [自动跟随与传送恢复](docs/FOLLOW_RECOVERY.md)。旧的穿线按键推进已移除；本文及该说明优先于旧版功能介绍中的惯移描述。

## 安装

1. **装 vnavmesh**（必需）：卫月 → 第三方仓库 → `https://puni.sh/api/repository/veyn` → 安装  
2. **装本插件**：将 `成品` 内 `AutoFollow.dll` + `AutoFollow.json` + `ImGui.NET.dll` 放到任意目录 → 卫月 → 插件 → 本地插件 → 添加 DLL  

编译 Release 后也会自动复制到仓库内 `成品/` 目录。

## 快速上手

```
/ftar         → 跟随当前选中目标
/ff           → 切换跟随开/关
F8            → 紧急停止（可改绑）
/fdbg         → 设置窗口
```

**迷你窗口**（默认显示，固定宽度不跳动）：

- **跟随** — 智能跟随：选中玩家则跟玩家；选中敌人则跟其当前目标  
- **暂停** — 紧急停止（不自动恢复）  
- **继续** — 优先智能跟随；否则恢复旧目标（旧目标须 ≤30y）  
- **▼/▲** — 玩家/旗标坐标；步行至flag（自动上坐骑）/ 飞行至flag / 停止移动  
- **飞行至flag** — 上陆行鸟后 `/vnav flyflag`；跨区自动找水晶传送；上马失败 5s 回退步行  
- **右键** — 打开主窗口 / 状态报告 / 紧急停止 / 30y 内队友 / 关闭窗口  
- **信息行** — 目标名固定 4 字宽（超宽截断+悬停全称）；引擎状态单字缩写（战/停/急/丢/黑/完/图/死），悬停显示完整原因

## 插件实际会做的事

| 场景 | 行为 |
|------|------|
| 目标走远 | 暂停循环输出 → vnavmesh 寻路追赶（A 方案：实时坐标替换路径起点，兼容国服特供版 VNA） |
| 距目标 ≤5y 或 ≤进入战斗区(默认10y) | 停移动 → **恢复**循环输出 → 进入 Combat 态 |
| **Boss 战**（坦克正在打 Boss） | 改按**离 Boss 目标圈外沿**停步（近战 2y / 远程 10y，按当前职能自动取），不再贴到坦克身边；小怪完全不受影响 |
| 距目标 > 离开战斗区(默认30y) 且非 Boss | **暂停**循环输出 → 继续跟随 |
| 进入 Boss 战 | 聊天提示一次「进入 Boss 战：<名称> Lv<等级>，将在圈外 10y 停下开打」 |
| 脱战约 1s 且距离仍近 | 保持停跟，避免贴脸反复横跳 |
| 目标距离 > 疾跑阈值(默认 **20y**) 或目标在跑 | 自动疾跑（可改无脑/仅战斗/坐骑） |
| 目标丢失（默认） | 单次有限尝试：30y 内接近最后可靠入口 → 有可靠轨迹时直走最多 2s/5y → 等待最多 10s；失败停止，完整路径恢复后再跟随 |
| 目标重现 | 验证身份与完整路径后自动恢复；不覆盖手动暂停和紧急停止 |
| 换图（默认） | 加载期间立即停止，完成后验证目标及路径；同地图传送也检测 |
| 跟随中队友传唤（默认） | 自动点「是」接受传送邀请 |
| 副本通关（默认） | 仅在跟随/追赶/战斗等活跃状态时**停止跟随并复位**：清空目标、按钮回「跟随」、恢复循环输出 |
| 地图在黑名单 | 暂停跟随 |

更细的状态机、命令语义与硬编码常量见 [`功能介绍.md`](功能介绍.md)。

| 命令 | 作用 |
|------|------|
| `/ft <玩家名>` | 按名字跟随 |

## 设置项（常用默认值）

| 参数 | 默认 | 说明 |
|------|------|------|
| 进入战斗区 | 10y | ≤ 此距离停跟并恢复输出 |
| 离开战斗区 | 30y | > 此距离恢复跟人并暂停输出 |
| Boss战按目标圈停步 | 开 | 只在跟随目标打 Boss 时生效，小怪不受影响 |
| 近战停步 | 2y | 坦克/近战DPS 与 Boss 目标圈**外沿**的距离，0 = 贴圈边 |
| 远程停步 | 10y | 远程DPS/法系DPS/治疗 与 Boss 目标圈**外沿**的距离 |
| Boss识别范围 | 40y | 只有此范围内的 Boss 参与判定（10~120y） |
| 疾跑触发 | **20y** | 智能疾跑阈值 |
| 扫描间隔 | 1 秒 | 坐标/路径更新周期（≤5y 停走为每帧） |
| 移动阈值 | 5y | 目标位移不足不重发路径 |
| 目标丢失后续行 | 开 | 其他控制；穿线键默认 W（按住型） |
| 换图后自动恢复跟随 | 开 | 其他控制 |
| 自动接受队友传送邀请（默认） | 仅识别队友邀请文案；副本入口确认仅按明确配置精确匹配 |
| 副本通关后停止并复位 | 开 | 其他控制 |
| 疾跑 | 开 | 智能疾跑 |
| 坐骑 | 关 | 与疾跑互斥 |
| 聊天提示 | 关 | 关闭后关键状态仍会输出指令日志 |
| 紧急停止热键 | F8 | 可改绑 |
| 循环暂停命令 | `/rotation off` | 默认 RSR |
| 循环恢复命令 | `/rotation Auto` | 默认 RSR |
| 按钮颜色 | 灰/绿/琥珀 | 可自定义 |

## 架构

```
Plugin (入口)
├── Configuration → FollowConfig (各项参数)
├── CustomCommandManager (/ff /ftar /fst 等命令)
├── FollowEngine (核心跟随引擎)
│   ├── IPCService → LoopController (暂停/恢复自动输出插件)
│   ├── VnavmeshFollow → VnavmeshIPC (寻路)
│   ├── ConditionManager (战斗/坐骑/死亡状态检测)
│   └── SprintController (疾跑/坐骑控制)
├── MiniWindow (迷你窗口：三态按钮 + 旗标折叠区)
└── DebugWindow (调试/设置窗口)
```

## 常见问题

**跟了不走？** 检查 vnavmesh 与 NavMesh；看 `/fdbg` → 指令日志是否有 move。

**循环不自动停/开？** 默认 RSR。AEAssist：暂停填 `/aestop`，恢复留空。

**怎么换目标？** `/ft 新名字` 或重新 `/ftar` / 迷你窗智能跟随。

**继续提示 >30y？** 迷你窗「继续」恢复旧目标时要求距离 ≤30y。

**迷你窗没了？** 卫月插件列表打开显示，或 `/fdbg`。

**飞行至flag 无效？** 需 vnavmesh；跨区需已开对应水晶；坐骑失败 5s 后回退步行。

**ProcessCommand 限制：** 只跑插件注册命令（如 `/vnav`）；`/mount`、`/tp` 无效，故上马与传送走 `UseAction` / `Telepo`。
