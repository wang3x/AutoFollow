# 强效跟随 AutoFollow

基于 **vnavmesh** 的 FF14 自动跟随插件。  
设定目标 → 自动追上 → 靠近后停跟并恢复输出 → 走远后继续追。

---

## 安装

1. **装 vnavmesh**（必需）：卫月 → 第三方仓库 → `https://puni.sh/api/repository/veyn` → 安装  
2. **装本插件**：将 `成品` 内 `AutoFollow.dll` + `AutoFollow.json` + `ImGui.NET.dll` 放到任意目录 → 卫月 → 插件 → 本地插件 → 添加 DLL  

编译 Release 后也会自动复制到仓库内 `成品/` 目录。

---

## 快速上手

```
/ftar         → 跟随当前选中目标
/ff           → 切换跟随开/关
F8            → 紧急停止（可改绑）
/fdbg         → 设置窗口
```

**迷你窗口**（默认显示）：

- **跟随** — 智能跟随：选中玩家则跟玩家；选中敌人则跟其当前目标  
- **暂停** — 紧急停止（不自动恢复）  
- **继续** — 优先智能跟随；否则恢复旧目标（旧目标须 ≤30y）  
- **▼/▲** — 玩家/旗标坐标；步行至flag / 飞行至flag / 停止移动  
- **飞行至flag** — 上陆行鸟后 `/vnav flyflag`；跨区自动找水晶传送；上马失败 5s 回退步行  
- **右键** — 打开主窗口 / 状态报告 / 紧急停止 / 30y 内队友 / 关闭窗口

## 插件实际会做的事

| 场景 | 行为 |
|------|------|
| 目标走远 | 暂停循环输出 → vnavmesh 寻路追赶 |
| 距目标 ≤5y 或 ≤进入战斗区(默认10y) | 停移动 → **恢复**循环输出 → 进入 Combat 态 |
| 距目标 > 离开战斗区(默认30y) 且非 Boss | **暂停**循环输出 → 继续跟随 |
| 脱战约 1s 且距离仍近 | 保持停跟，避免贴脸反复横跳 |
| 目标距离 > 疾跑阈值(默认 **20y**) 或目标在跑 | 自动疾跑（可改无脑/仅战斗/坐骑） |
| 目标丢失（默认） | 先去最后已知点 → 再面朝方向惯移最多 2s；重现则继续跟 |
| 目标从 ≤100y 突然 >100y | 先去最后已知点 → 面朝方向惯移 1.5s + 等待 0.5s → 再正常追 |
| 换图（默认） | 落地约 1.5s 后若仍有旧目标则自动再跟 |
| 跟随中队友传唤（默认） | 自动点「是」接受传送邀请 |
| 副本通关（默认） | 自动暂停跟随 |
| 地图在黑名单 | 暂停跟随 |

更细的状态机、命令语义与硬编码常量见 [`功能介绍.md`](功能介绍.md)。

## 其他命令

| 命令 | 作用 |
|------|------|
| `/ft <玩家名>` | 按名字跟随 |
| `/fes` | 紧急停止 |
| `/flp` | 发送循环**暂停**命令 |
| `/flr` | 发送循环**恢复**命令 |
| `/flt` | 当前实现为再发一次**暂停**（不是真切换） |
| `/fst` | 状态报告 |

## 设置项（常用默认值）

| 参数 | 默认 | 说明 |
|------|------|------|
| 进入战斗区 | 10y | ≤ 此距离停跟并恢复输出 |
| 离开战斗区 | 30y | > 此距离恢复跟人并暂停输出 |
| 疾跑触发 | **20y** | 智能疾跑阈值 |
| 扫描间隔 | 2 秒 | 坐标/路径更新周期（≤5y 停走为每帧） |
| 移动阈值 | 5y | 目标位移不足不重发路径 |
| 目标丢失后续行 1.5s | 开 | 其他控制 |
| 换图后自动恢复跟随 | 开 | 其他控制 |
| 自动接受队友传送邀请 | 开 | 其他控制 |
| 副本通关后暂停跟随 | 开 | 其他控制 |
| 疾跑 | 开 | 智能疾跑 |
| 坐骑 | 关 | 与疾跑互斥 |
| 聊天提示 | 关 | 关闭后关键状态仍会输出指令日志 |
| 紧急停止热键 | F8 | 可改绑 |
| 循环暂停命令 | `/rotation off` | 默认 RSR |
| 循环恢复命令 | `/rotation Auto` | 默认 RSR |
| 按钮颜色 | 灰/绿/琥珀 | 可自定义 |

## 架构

```
Plugin (入口)
├── Configuration → FollowConfig (各项参数)
├── CustomCommandManager (/ff /ftar /fst 等命令)
├── FollowEngine (核心跟随引擎)
│   ├── IPCService → LoopController (暂停/恢复自动输出插件)
│   ├── VnavmeshFollow → VnavmeshIPC (寻路)
│   ├── ConditionManager (战斗/坐骑/死亡状态检测)
│   └── SprintController (疾跑/坐骑控制)
├── MiniWindow (迷你窗口：三态按钮 + 旗标折叠区)
└── DebugWindow (调试/设置窗口)
```

## 常见问题

**跟了不走？** 检查 vnavmesh 与 NavMesh；看 `/fdbg` → 指令日志是否有 move。

**循环不自动停/开？** 默认 RSR。AEAssist：暂停填 `/aestop`，恢复留空。

**怎么换目标？** `/ft 新名字` 或重新 `/ftar` / 迷你窗智能跟随。

**继续提示 >30y？** 迷你窗「继续」恢复旧目标时要求距离 ≤30y。

**迷你窗没了？** 卫月插件列表打开显示，或 `/fdbg`。

**飞行至flag 无效？** 需 vnavmesh；跨区需已开对应水晶；坐骑失败 5s 后回退步行。

**ProcessCommand 限制：** 只跑插件注册命令（如 `/vnav`）；`/mount`、`/tp` 无效，故上马与传送走 `UseAction` / `Telepo`。
